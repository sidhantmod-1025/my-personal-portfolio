## 🌐 About the Project

This personal portfolio website is designed to present my
developer profile in a modern, interactive, and professional way.

It features a dark theme, glassmorphism-inspired UI, cyan and purple
accents, smooth GSAP animations, and a responsive layout for different
screen sizes.

The website also includes a contact form powered by EmailJS.
